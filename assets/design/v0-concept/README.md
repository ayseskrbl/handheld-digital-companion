# V0 — Initial Concept

**Date:** November 18, 2026

## Overview

This folder contains the initial concept sketches of the handheld electronic device.

## Initial Design Ideas

- Circular handheld enclosure
- 1.28-inch round LCD display
- Rotating display module (180°)
- Initial scissor linkage mechanism
- Pull-based opening concept
- Rear side of the display module reserved for a logo

## Open Questions

- How can the display rotate while keeping the enclosure compact?
- Which hinge mechanism would work best?
- How should the internal components and cables be arranged?
- What is the most intuitive opening mechanism?

## Status

Initial concept stage. Mechanical design and component layout are subject to change.
